# v0.1.18 — Safe runtime bootstrap during catalog lag

Tested with Pi 1.5.0 and Node.js >=22.19.0. ACP SDK 2.2.0 still negotiates **ACP protocol 1**, not experimental protocol v2. Host Pi packages remain wildcard peers; permission defaults are unchanged.

## Fixes and updates

- Allow explicit runtime updates to install the latest approved signed release when the official registry is newer than the signed catalog, matching automatic setup. Report the pending upstream version instead of blocking fresh installations. Keep signature verification, archive integrity, ACP identity validation, external-runtime ownership, and downgrade protection unchanged (#78, fixes #65).
- Document a programmatic bootstrap path: `approvalPending` is advisory, not a reason to reject an otherwise installable approved release. Downstream adapters that abort on this flag must adopt the documented logic.
- Bundle the signed Antigravity ACP 1.4.5 catalog for all six supported platform/architecture combinations (#75).
- Share one ACP runtime/provider per Pi process across extension instances. Closing one Pi session releases only that session's binding while retaining saved restoration state; final application shutdown closes the shared stack (#67).
- Report Antigravity's fixed quota-exhaustion replies as errors, including an ISO reset time when available, instead of saving them as successful turns. Keep the healthy ACP session warm without automatic retries (#70).
- Migrate from ACP SDK 1.8.0 to 2.2.0's client app API, consistently using the full-v1 `/unstable` entrypoint for existing draft usage and session lifecycle fields. Preserve legacy model selection, stable configuration selectors, cancellation notifications, permission handling, and immediate lifecycle shutdown (#77).
- Update MCP SDK to 1.32.2 and both Pi development packages to 1.5.0. Resolve dependency audit blockers with patched Hono/Undici/minimatch versions and remove the obsolete development Undici override (#74, #76).

## Validation

- Clean installation, typechecking, and **321 ordinary tests** pass; eight opt-in official-runtime/live tests remain skipped.
- Package dry runs and isolated packed-install smoke tests pass with the bundled npm CLI and npm 12.
- Full dependency audit reports **zero vulnerabilities** at release validation time.
- CI checks Node 22.19.0 and 24 before release publication. Publication uses the existing npm trusted-publishing/OIDC workflow, without a long-lived npm token or protection bypass.

No authenticated prompt, new OAuth flow, real-account quota exhaustion, or cross-platform runtime qualification was exercised for this release. Synthetic tests and signature verification do not establish inference entitlement. The provider is not a sandbox.
