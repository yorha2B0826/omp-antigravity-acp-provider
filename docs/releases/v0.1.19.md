# v0.1.19 — Live quota and per-inference context usage

Tested with Pi 1.5.0 and Node.js >=22.19.0. ACP SDK 2.2.0 still negotiates **ACP protocol 1**, not experimental protocol v2. Host Pi packages remain wildcard peers; permission defaults and the signed runtime catalog are unchanged.

## Fixes and updates

- Size Pi's context from the latest ACP `usage_update.used` rather than summing every inference in a tool-heavy prompt. Intermediate tool-use messages now carry context usage, while the final message retains the aggregate input/output/cache breakdown for process accounting. Runtimes without usage updates retain the previous fallback (#83, related to #80).
- Include Gemini thought tokens in output usage and avoid counting them twice in process totals. Correct the observed duplicate cache-read contribution for single-inference prompts; multi-inference prompts with cache reads can still overestimate context by the final inference's cached tokens. The cache correction was observed on Antigravity ACP 1.4.3 and has not been independently reverified with cache hits on 1.4.5 (#83).
- Show live Antigravity quota groups, remaining percentages, and UTC reset times with `/antigravity-acp quota`. Read Antigravity's own `/usage` command through a separate short-lived ACP process, cache successful snapshots for 60 seconds, coalesce concurrent reads, and clean up the throwaway conversation files after process exit (#71).
- Expose live quota to other extensions through `antigravity-acp:quota:request`. Reply exactly once per emitted request object even when several provider instances share an event bus; preserve the surviving listener after another instance shuts down. Closed runtimes reject quota reads, and logout invalidates cached and in-flight account state (#71).
- Isolate ordinary tests from the developer's real Antigravity home, canonicalize temporary paths for macOS runtime-update tests, and make the quota-reset assertion deterministic when an ISO timestamp contains `.429Z` (#81, #82).

## Validation

- Clean installation, typechecking, and **356 ordinary tests** pass; eight opt-in official-runtime/live tests remain skipped.
- Package dry runs and isolated packed-install smoke tests pass with the bundled npm CLI and npm 12.
- Full dependency audit reports **zero vulnerabilities** at release validation time.
- CI checks Node 22.19.0 and 24 before release publication. Publication uses the existing npm trusted-publishing/OIDC workflow, without a long-lived npm token or protection bypass.

No authenticated prompt, new OAuth flow, live account quota query, real-account quota exhaustion, or cross-platform runtime qualification was exercised during release validation. The quota feature's upstream runtime observations are documented in #71; synthetic tests do not establish current account quota or inference entitlement. The provider is not a sandbox.
